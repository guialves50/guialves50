## Sobre

Desenvolvedor back-end na **Comber Indústria** (Rio Verde, GO) e estudante de Ciência da Computação na UniRV.

Meu trabalho fica na fronteira entre software e chão de fábrica: sistemas que leem sensores, controlam equipamentos via **Modbus TCP** e rodam em produção dentro de PCs industriais e Raspberry Pi, na planta do cliente. Em paralelo, desenvolvo APIs em **TypeScript/Node.js** com foco em testes, CI e modelagem de regras de negócio.

## Experiência e projetos

### Automação industrial — Comber Indústria
`Python` `Modbus TCP` `DDD` `Raspberry Pi` `Linux`

Sistema de automação embarcado em PCs industriais instalados na planta do cliente.

- Comunicação com CLPs via Modbus TCP: leitura de temperatura de fornalhas e secadores, acionamento de equipamentos por coils e holding registers
- Otimização automática de ganhos de PID com modelos de machine learning rodando na borda
- Arquitetura orientada a domínio (DDD), tratamento de erros padronizado e logging estruturado
- Persistência dos dados de processo para análise e interface web de supervisão
- Acesso remoto seguro às redes industriais via Tailscale (subnet routing)

### API de gestão de comissões
`TypeScript` `Node.js` `Express` `Prisma` `PostgreSQL`

Back-end para gestão de comissões comerciais.

- Autenticação JWT baseada em cookies e controle de permissões por usuário
- Suíte de testes unitários e de integração com Vitest, contra banco PostgreSQL isolado
- Pipeline de CI no GitHub Actions e graceful shutdown da aplicação
- Modelagem das regras financeiras de comissão por recebimento

### Jarvis — assistente de voz
`Raspberry Pi` `Whisper` `Piper` `Home Assistant`

Assistente de voz para escritório com o Raspberry Pi como orquestrador: wake word, reconhecimento de fala com Whisper, síntese com Piper e integração com Home Assistant para controle de dispositivos IoT.
